# Pet art

Everything in this folder is generated by `tools/render.py`. To change a pet's look, animation or
sounds, edit its renderer in `tools/pets/` (or `tools/sounds.py`) and run it again:

```
pip install -r tools/requirements.txt
python tools/render.py              # all pets, treats, effects and sounds
python tools/render.py goldfish     # just one pet (plus treats and effects)
```

You can drop real recordings in as `sound1.wav`, `sound2.wav` and so on to replace the synthesized
ones. Re-rendering that pet overwrites them.

Layout:

```
assets/<pet>/
  idle.png      standing / breathing loop
  walk.png      walking, swimming or flying, facing right
  action.png    bark / meow / blub and jump; also used for alerts and falls
  sleep.png     optional: first idle frame if missing
  eat.png       head down chewing; falls back to action
  eat1.wav ...  chomp played on each bite
  sound1.wav    one is picked at random each time
treats/  bone.png, fish.png, flakes.png, seeds.png, meat.png   (one strip, whole -> almost gone)
fx/      heart.png, z.png, bubble.png, crumb_<treat>.png
```

- Each `.png` animation is a horizontal strip of equal-width frames. The frame count is stored in
  the PNG's `frames` text chunk; without it the file is treated as a single frame.
- Instead of a strip you can use an animated GIF per state, for example `idle.gif`.
- Draw every frame facing right; the app mirrors them when the pet turns left.
- Use square frames with the feet touching the bottom edge. The rendered frames are 256×256 and
  get scaled to the chosen size.
- Full alpha transparency is supported, including soft edges and shadows.

Rebuild the app after changing art (`packaging/windows/build.bat` or `packaging/linux/build.sh`), because the assets are bundled inside it.
